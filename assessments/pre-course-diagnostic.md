# Pre-Course Diagnostic

Time: 30 minutes. This is placement evidence, not a graded test.

## Questions

1. Explain the difference between an interface and its implementation.
2. Why might an immutable object help in a concurrent application?
3. What is the purpose of a Maven dependency?
4. Name the Maven phases that compile, test, and package a project.
5. What do HTTP 400, 401, 429, and 500 broadly indicate?
6. Why should a secret not be committed to Git?
7. What is dependency injection?
8. Write a Java record for `Question(id, text, category)`.
9. What is the difference between syntax validation and a business rule?
10. A method calls a remote API. Name four possible failures.
11. What does “retry” mean, and when can it be dangerous?
12. What is JSON?
13. Explain authentication versus authorization.
14. What is a unit-test stub or fake?
15. Which part of an AI application do you expect to be probabilistic?

## Trainer interpretation

- 12–15 strong: proceed; use stretch questions.
- 8–11 ready: standard course pacing.
- 5–7 needs a Java/Maven/HTTP refresher before Day 4.
- 0–4 needs prerequisite instruction before the course.

Do not penalize questions 15 or AI terminology; the diagnostic primarily checks application-development foundations.
