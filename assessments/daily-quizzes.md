# Daily Quizzes

Five questions per day. Suggested time: 10–12 minutes.

## Day 1

1. Which statement best describes inference?  
   A. Compiling Java B. Using a trained model C. Indexing Maven D. Writing rules
2. State one task that should remain deterministic Java logic.
3. Does RAG change model weights?
4. Name two responsibilities Java retains around a model call.
5. Why is HTTP success not enough to accept generated output?

## Day 2

1. Is a token always a word?
2. List four consumers of the context window.
3. What does temperature control where supported?
4. Why clone arrays in an embedding record?
5. Name two controls still required when using virtual threads.

## Day 3

1. List four parts of a prompt specification.
2. Is retrieved text trusted as an instruction?
3. What does structured output guarantee—and not guarantee?
4. When are few-shot examples valuable?
5. Why should prompts be versioned?

## Day 4
