# Security Guidance for This Training Repository

This repository contains documentation fragments only. Do not add live API keys, credentials, private endpoints, customer data, production prompts, or unredacted logs.

If a secret is committed:

1. revoke or rotate it immediately;
2. notify the responsible security/operations channel;
3. remove it from current content and follow organizational history-rewrite policy;
4. inspect usage and logs for abuse;
5. document the incident without repeating the secret.

Security issues in the teaching content should be reported privately to the repository owner rather than demonstrated with real systems or data.
